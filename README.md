# 0\ CloudBox — Спец Поиск для кнопочных телефонов

> Приватная поисковая система с минималистичным дизайном, созданная специально для кнопочных телефонов (Nokia, Symbian, S40/S60) и старых мобильных браузеров (Opera Mini, WAP).

(>) **Демо:**
[;)](https://hz405066-byte.github.io/Search-CloudBox/)
> Можите сразу использовать сайт на кнопочных телефонах как поисковик.
---

## [] Особенности

- **/0 Веб-поиск** — поиск по встроенной базе сайтов с подсветкой совпадений
- **[img] Поиск картинок** — агрегация превью из нескольких открытых источников:
  - Wikimedia Commons
  - Openverse
  - Flickr (JSONP, без ключа)
  - Reddit
  - Pixabay (опционально, с API-ключом)
  - Google / Яндекс (через прокси, отключено по умолчанию)
- **(18-) Фильтр безопасного поиска** — включается/выключается в один клик
- **[-0] Встроенный просмотрщик фото** — листание, переход на источник
- **(#) Выбор поисковых систем** — чекбоксы для включения/отключения источников картинок
- **√ Тёмная тема** — комфорт для глаз, экономия заряда на AMOLED
- **[_-"] Оптимизация под 2G** — минимум графики, лёгкая вёрстка, быстрые запросы
- **∆ Категории базы** — программирование, поисковики, новости, музыка, погода, Википедия, видео, игры, спорт, чат и соцсети
